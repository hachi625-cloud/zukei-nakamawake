# さんかくけい・しかくけい なかまわけ

小学2年生の算数「三角形と四角形」を、かたちを手で動かしながら考える学習アプリです。
9つのかたち（ア〜ケ）をトレイからつまんで、「三角形」「四角形」「どちらでもない」の3つのはこに分けます。

## 特徴

- **ドラッグでなかまわけ** — かたちのカードをつまんで、はこに入れる
- **タップで拡大** — かたちをタップすると、大きく表示して細かいところまで見られる
- **話し合いをうながす** — ぜんぶ分け終わると「どうしてそのはこに入れたのか、話し合ってみよう」というメッセージが出る（答え合わせはあえてしない）
- **やり直し** — 「↺ もういちど」でいつでも最初から

「どちらでもない」には、辺がへこんでいたり、かどが丸まっていたり、線が途切れていたりする図形が入ります。正解を教えるのではなく、「なぜ三角形・四角形と言えないのか」を子ども自身が説明することをねらいにしています。

## 使い方

`index.html` をブラウザで開くだけです。ビルドやインストールは不要です。

```
git clone https://github.com/hachi625-cloud/zukei-nakamawake.git
cd zukei-nakamawake
```

あとは `index.html` をダブルクリック、または GitHub Pages などで公開して使えます。

## 対象

- 学年: 小学2年生
- 教科: さんすう（算数）
- 単位: 三角形と四角形

## 技術メモ

- HTML1ファイル（`index.html`）のみ。外部ライブラリなし
- 図形は SVG、操作は Pointer Events によるドラッグ＆ドロップ
- Web フォント（Zen Maru Gothic）のみ外部から読み込み。オフラインでも動作する
